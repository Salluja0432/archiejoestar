# Jovem Tech — Módulo 2

Repositório de registro dos estudos, exercícios e práticas desenvolvidos durante o Módulo 2 do programa Jovem Tech.

## Conteúdos estudados

Ao longo do módulo, foram trabalhados os seguintes assuntos:

1. Decomposição de problemas e pseudocódigo.
2. Variáveis, tipos de dados, operadores e entrada e saída de informações.
3. Git e GitHub para versionamento e organização de projetos.
4. Laços de repetição e funções modulares.
5. Vetores, matrizes e funções.
6. Strings, pesquisa de dados, casos de teste e depuração.

## Atividades e organização

A branch preserva os arquivos que já estavam na branch `main` quando `module2` foi criada, incluindo exercícios e códigos de prática.

- **`atividades_de_casa_e_aula/`** — exercícios em JavaScript realizados durante as aulas e em casa.
- **`lista de atividades 1 thru 3 + extras/`** — arquivos reunidos das listas de atividades e exercícios extras.
- **`originais_atividades_iniciais/`** — versões originais de exercícios iniciais.
- **`originais_com_problemas/`** — versões anteriores de códigos que apresentaram problemas, mantidas para consulta e comparação.
- **`pedra.js`** — prática adicional: jogo de Pedra, Papel e Tesoura.
- **`package.json`** — registra a dependência `prompt-sync`, utilizada em exercícios que recebem entrada pelo terminal.

Para instalar as dependências do projeto:

```bash
npm install
```

Os arquivos são exercícios de aprendizagem e podem representar diferentes etapas de desenvolvimento; nem todos correspondem à versão final de uma atividade.

## Projeto final — Jogo da Velha

O projeto final do módulo foi desenvolvido e apresentado em um repositório colaborativo da squad. A versão final inclui:

- modo para dois jogadores;
- modo jogador contra máquina;
- partidas em melhor de cinco, com vitória para quem alcançar três rodadas;
- seleção aleatória, pela máquina, entre as posições disponíveis.

A máquina utiliza escolhas aleatórias, não uma estratégia de inteligência artificial.

**Código final:** [Jogo da Velha — branch `artur`](https://github.com/jhonatas23/jovemtech_jogo_da_velha/blob/artur/jdv3final.js)
